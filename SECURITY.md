# Security

ClauseScope is a portfolio prototype, not a hosted legal service.

- Use only synthetic or non-sensitive documents in the local demo.
- Authentication is disabled by default for local development.
- Basic Auth is available only for a private instance behind HTTPS; it is not a production identity system.
- Uploaded temporary files are deleted after processing, but persisted evidence may contain contract excerpts.
- Never commit credentials, private contracts, generated databases, or upload directories.

Please report security concerns privately through the contact options on the maintainer's GitHub profile rather than opening a public issue.
